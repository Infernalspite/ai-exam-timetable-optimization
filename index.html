The randomized algorithms at work

① Randomized Primality Testing — Miller–Rabin

Hash table size must be prime to spread keys evenly. Miller–Rabin tests random witnesses: fail one → definitely composite; pass all → prime with error ≤ 4−k.

② Randomized QuickSort — by conflict-degree

Random pivot → partition → recurse. Expected O(n log n) on any input order — the adversarial toggle feeds pre-sorted data that would break a fixed-pivot Quicksort with O(n²).

③ Randomized Select — the K most conflict-heavy courses

Need the Kth smallest without a full sort? QuickSelect partitions like QuickSort but recurses into one side only: expected O(n) vs O(n log n) for sorting everything.

AI refinement — Genetic Algorithm

Population of timetables → fitness = conflict penalty → selection → crossover → mutation. The fast randomized subroutines above are what let every generation evaluate candidates quickly.
