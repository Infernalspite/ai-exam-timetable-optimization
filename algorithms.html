The algorithms, measured live

Each card runs real instrumented code on a synthetic semester — no canned numbers. Re-run any time; the seed keeps it reproducible.

① Randomized Primality Testing — Miller–Rabin

The conflict hash table is sized to a prime so keys scatter evenly. Miller–Rabin tests random witnesses: fail a single round → definitely composite; pass all k rounds → prime with error ≤ 4−k. Polynomial time, tiny error — the textbook trade.

② Randomized QuickSort — by conflict-degree

A random pivot, a partition, two recursive calls. Expected O(n log n) regardless of input order. Tick adversarial input to pre-sort by conflict-degree — a fixed first-element pivot collapses toward O(n²) while the random pivot shrugs.

③ Randomized Select — the K most conflict-heavy courses

QuickSelect partitions like QuickSort but recurses into one side only: expected O(n) to find the Kth smallest — versus O(n log n) to sort everything when you only need the top handful.
