Unit V — complexity summary

Randomized algorithmRole in this schedulerBestAverage (expected)WorstReliability
Randomized QuickSort Sorts courses by conflict-degree so constrained courses are placed first Ω(n log n)O(n log n)O(n²) — probability → 0 Input-order independent in expectation
Randomized Select (QuickSelect) “Top-K most constrained courses”, “K least-loaded slots” without full sort Ω(n)O(n)O(n²) — probability → 0 Beats full sort whenever K ≪ n
Miller–Rabin primality test Verifies prime hash-table sizes for O(1) conflict lookups O(k · log³ n) — polynomial Deterministic factoring: exponential One-sided error ≤ 4−k (false “prime” only)
Greedy coloring (deterministic harness) First-fit initial timetable on the QuickSort order O(V + E) per pass Guaranteed conflict-free if colors suffice
Genetic Algorithm / Simulated Annealing (AI layer) Repairs tight instances: unassigned courses, residual conflicts, load balance Empirical — population × generations / iterations Anytime: better schedules over time

Recorded-demo script matches a 5-minute video, section by section

  1. Open the Live Scheduler and run with defaults (60 courses, 800 students, 12 slots) — all four stages light up; the result panel shows 0 hard conflicts.
  2. Point at stage 1's metric: prime table size 83 gives 10 collisions while a power-of-2 table needs 36 — that is “why prime sizes” in one glance.
  3. Switch to Algorithms, tick Adversarial input, re-run: the fixed-pivot QuickSort balloons to ~4× comparisons; the randomized pivot barely moves.
  4. Same page: QuickSelect finds the top-10 most constrained courses with roughly a third of a full sort's comparisons.
  5. Back to Live Scheduler, switch the refiner to Simulated Annealing, re-run — it also converges to zero conflicts.
  6. Close on the Reference page — this complexity table — and link the GitHub repo.

Project structure

> index.html · algorithms.html · scheduler.html · reference.html  — the four pages
> styles.css  — the cream / sky / blush pastel theme
> js/rng.js  — seeded RNG (mulberry32), reproducible runs
> js/primality.js  — Miller–Rabin, BigInt-safe modular arithmetic
> js/hashtable.js  — chain tables, prime vs power-of-2 sizing
> js/quicksort.js  — randomized QuickSort + fixed-pivot comparator
> js/quickselect.js  — randomized Select, topK / bottomK
> js/coloring.js  — greedy graph coloring + conflict counters
> js/scheduler.js  — GA & simulated annealing with Kempe swaps
> js/render.js  — all rendering: graph, chart, timetable, logs
> js/app.js  — dataset generation + page-aware pipeline
> js/home.js  — the little hero graph on the home page
